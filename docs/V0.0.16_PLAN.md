## 验收门禁

- 构建、JS 语法、npm run audit、既有回归与 AI 协议；结构审计不通过不交付。
- 桌面/手机/短屏，侧栏与沉浸进出，字号和正文宽度几何，空白角色和超长无空格文本卡片宽度不低于容器 80%。
- 预览与实际发送一致；切书隔离，源编辑回写、自定义楼层持久化、白鸟锁定。
- 导入取消无写入、无效 JSON 无写入、选区导入和合入、关联 ID、一致性、预设独立导出。
- 快速重复点击、重排中的异步返回、网络错误、取消/切书后的旧请求隔离。
- 长书加载/操作/流式生成性能，结果不丢字，保存后刷新一致。
