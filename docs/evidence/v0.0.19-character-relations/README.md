# 角色阵营、状态色与长书上下文证据

2026-11-18，本地 v0.0.19 热更新。范围、方案、命令和限制见[专项报告](../../V0.0.19_CHARACTER_CONTEXT_REPORT.md)。本轮未部署。

- `gate-summary.json`：完整浏览器门禁 22/22，基线为工作区修改前提交，运行时工作区有本轮修改；含构建、语法、结构审计与 302 项 v19 回归。仅归档摘要，不含原始本机路径与请求正文。
- `synthetic-results.json`：最终增强角色专项 20/20。3 个合成角色、双向关系与 2 个势力（含未关联和超长名称），测试勾选、编辑／新建、状态色、保存刷新、导出导入及实际 mock 请求。
- `private-counts.json`：原备份经隔离页面原生导入后的 3 项匿名统计。双开关全关／全开均发 1 次请求；同章 69,412 字符，57/57 合并记忆进入。没有私稿、真实请求或素材名。
- `backup-audit-counts.json`：原备份只读计数和历史请求长度；不含原文件路径、书名、人物名或原始文字，文件指纹仅本机保留。
- `1280-*`、`1024-*`、`360-*`：电脑、平板和手机明暗两主题合成截图；`-profile` 是阵营档案，其余是关系图。768、320 的几何和点击命中记录在专项 JSON 中。

方法：本机 Edge 隔离资料、HTTP 本地页面；mock 使用 OpenAI 兼容流式协议，Gemini 输入改写与抗截断全开／全关分别检查最终请求。模拟只证明应用发送与显示，不证明真实 Gemini／DeepSeek 的事实遵循。脚本阻止其他 fetch 外发，没有调用真实服务商。

未覆盖用户真机、厂商浏览器、真实模型续写和线上发布。记忆选材优化仅提出方案，未实施；本地门禁通过不能解释成“长书人物错乱已解决”。
