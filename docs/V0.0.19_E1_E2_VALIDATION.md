## 改动与检查发现

- 后续细纲只发送标题和停笔说明；末尾校验按当前章号限制剧情；白鸟作者证据移除新旧后续预告和执行铁律。本章和前文细纲的原处理保留。三处均注明原因。
- 目录按当前分支的可见章号分卷，保留章节跳转、高亮和摘要编辑；无卷书不增加分组标题，未归属章单独放最后。
- 卷交接支持目录编辑、实际卷纲修正折叠、时间及分支标识。目录、总结页和 AI 生成共用保存函数，写回原卷及对应总结；主线同步旧兼容字段，分支互不覆盖。保存清除过期标记。
- 手改交接后重新生成先确认；取消不请求。生成等待期间切书、切分支、修改正文或交接，迟到结果不覆盖新内容。缺少总结 API 时提示配置原因，保留旧交接。
- 页面实测补修两项：普通章节保存原来没有标记卷交接过期，现复用原有标记函数；正文生成函数引用了另一个函数的局部变量 `requestModuleKey`，现从当前运行参数取值，连续生成已实测走通。
- 原交接生成写入规范化卷副本的持久化问题已修复，统一按卷 id 定位书里的原卷保存。
