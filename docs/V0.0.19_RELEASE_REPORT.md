## 边界与回滚

最没有把握的仍是不同真实服务商的长输出、限流/中断及最终剧情质量；本地假模型和线上静态页面验收不能证明这些。手机使用桌面 Edge 视口模拟，iOS Safari、实体手机软键盘和手势未覆盖。整段总纲按当前章裁剪仍是此前明确保留的已知问题；角色和世界观继续按书共享，不能把分支规划隔离扩大理解为所有设定独立。

最大的后续缺口是真实书籍在多轮长时间生成中的回测，需要用户用备份副本继续检查真实上下文与生成内容。当前在已覆盖范围内未发现问题，不宣称所有服务商均已兼容。
