## 更新说明

1. 修复二轮／三轮补写开关在手机上的变形、错位。复用现有的 `moyun-toggle-hitbox`，将点击区域与可见轨道分开：轨道保持 44×24，点击区域至少 44px，开关名称、事件与状态含义保持原样。
2. 全局设置的分类栏固定留在标题下方，内容在它下方单独滚动，不再随长内容滑到弹窗中间。
3. 手机工作区、侧栏和弹窗跟随浏览器实际可视高度和顶部偏移，工具栏或键盘出现时，底部操作随可视区调整。去掉按机型猜测 56／72px 底栏的逻辑；正常浏览器不凭空增加底部空白。
4. 短屏时压缩设置头部间距，隐藏重复的自动保存说明；横屏续写区利用同行空间，保留关闭、完成与生成按钮。分支弹窗沿用已调整的弹窗容器，不重复计算键盘偏移。
5. 修复触屏平板双栏下续写框下半部分落到屏幕外。工作区共用实际可视高度，触屏平板的弹窗与浮动操作同步避让工具栏；保留侧栏与阅读区双栏，不强制切成手机布局。

根因是三处布局规则相互叠加：手机按钮最小高度撑高了直接作为按钮的开关轨道；分类栏位于滚动内容内，并带固定的 sticky 顶部距离；`h-screen` 的 `100vh` 覆盖页面高度，使页面底部仍停在浏览器布局视口，而不是当前可见区域。

平板补充：早期可视区修复限定在小于 768px，遗漏了仍以双栏显示的平板。用户截图中可见续写输入框和半截图标，生成按钮落在画面外；这是底部布局越界，不是书籍内容被删除。截图的实际 CSS 宽高未知，未把图片像素当作设备分辨率。

## 界面与代码取舍

这是写作工作区的适配修复。继续使用原有字体、颜色、边框、圆角和明暗主题，不引入新库、图片或动画。工作区共用实际可视高度；弹窗和浮动操作的避让覆盖手机与粗指针触屏设备。手机固定顶栏／侧栏的偏移仍只用于小于 768px，避免平板双栏重复移位。没有 `visualViewport` 时回退到 `innerHeight`；样式保留 `100vh`／`100dvh`。安全区继续使用现有 `env(safe-area-inset-*)`。

开关保留 `role=switch`、`aria-label`、`aria-checked`，支持原生按钮键盘操作；状态除颜色外仍由滑块位置和无障碍属性表达。普通、关闭／开启、长内容滚动、短可视区及恢复桌面均纳入检查。未新增生成、保存或错误状态。删除失效的键盘定位样式与机型兜底函数，并登记已删除符号，避免重复处理。
