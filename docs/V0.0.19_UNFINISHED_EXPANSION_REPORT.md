# v0.0.19 未完模式与已有规划扩展验收报告

日期：2026-11-15
分支：`v0.0.19/L1-foundation`
源码：`source/moyun.single.html`

## 本轮完成内容

- 普通“一键开书”的“预设模块”新增独立“未完模式”开关，创建书籍时直接写入书籍数据；团队开书和已有书籍入口继续沿用同一状态。
- 已有大纲或细纲时，预设页说明改为“当前已有大纲与细纲，只能创造新内容章节”，并明确保留旧内容、允许在未写正文的细纲之间插入新章、向后追加和重新划分卷纲。
- 新增剧情规划会读取当前书的最新大纲、全部细纲、卷纲和当前分支交接；模型必须返回完整 `chapterPlan` 与完整 `volumes`。旧章只用 `existingChapterNo` 引用，新章必须有标题和完整细纲。
- 规划结果先进入现有红绿对比审阅。接受后才写入新增细纲、章节索引、暗线引用、大纲追加和卷纲；拒绝、解析失败、范围错误、刷新恢复或撤销都不会覆盖原规划。
- 已写正文之前插章会明确提示先创建分支；末尾追加可以继续。未完模式的规划提示固定要求只规划当前一段、禁止写结局。
- 普通新书入口、已有书籍入口和移动端预设页均保留二次确认关闭未完模式；确认后写入 `unfinishedModeClosed`，刷新后不能重新开启。
