基于已发布候选 `1a86b37`，改前创建分支 `fix/v0.0.19-reader-navigation-settings`。继续作为 19 热更新，不修改页面内 1116 公告。

## 调整

在「全局设置 → 上下文 → 生成开始时定位」下方加入“正文上下跳转按钮”开关，默认关闭，旧设置缺少该字段时也保持关闭。开启后展开两个数字输入：连续滚动多久后显示（默认 0.5 秒，0～30 秒），停止操作多久后隐藏（默认 3 秒，1～60 秒）。

显示依据从速度改为持续滚动时间；停顿超过 250 毫秒后重新累计，零秒表示滚动即显示。程序自动定位不会触发；关闭、切书／分支／工作台以及修改时间均清理显示状态与定时器。已有顶部／底部跳转、44px 按钮及手机位置保留。设置沿用现有 settings 与 `DB.saveLibrary`，不增加存储键、数据库、组件库或 AI 请求。

复用原开关与输入框样式，无新增 CSS。设置搜索增加“上下箭头／上下顶按钮／回到顶部／自动消失／显示时间／隐藏时间”等关联词。
