## 本轮补救的直接原因

细纲打不开：模板仍调用已删除的 canUndoChapterOutlineAi。移除失效撤销入口，改用细纲历史恢复并补齐模板导出。
弹窗不显示：in-DOM Vue 模板中的 branch-panel 使用自闭合标签，HTML 解析把后续弹窗收进组件内。改为显式闭合；structure-audit 增加自定义组件闭合检查。
另外修复团队提交重复创建、角色乱序错配、流式细纲预览被误当已有而跳过最终写入、非流式截断丢失 partialText、失效分支回退和支线导出污染风险。
