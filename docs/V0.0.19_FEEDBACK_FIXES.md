## 更新说明

- **大纲/细纲卷纲整理**：AI 修改大纲、细纲输入和单章细纲入口的卷纲整理候选统一放进独立审阅弹窗。弹窗在桌面居中、手机全屏，正文区独立滚动；接受前不改原卷纲或任何细纲。卷纲整理请求明确读取全书大纲、全部细纲、现有卷纲和当前分支交接，只返回连续、不重叠、覆盖全部章节的卷分类 JSON；范围无效或没有可归类章节时拒绝写入。候选保存细纲基线，审阅期间细纲被改动会阻止覆盖并提示重新整理。普通细纲输入仍只改当前章节，包含“卷纲/分卷”要求时改走同一候选审阅流程。

- **续写框**：缩短标签、合并工具行、去掉空提示占位。输入区作为正文滚动区外的底栏占用实际空间，正文末尾不会被浮层盖住。输入较长时只在卡片内滚动；收起后保留文字。没有以缩小按钮点击区域来压高度。
- **喜欢**：移到每章底部删除按钮左侧，直接显示爱心。没有喜欢时灰色，整篇或任一段落已喜欢时红色实心；点击仍打开整篇／段落选择。段落用相同的居中 SVG，图形 20×20、点击区 44×44，无外围圆圈，不依赖段评开关。
- **团队开书**：策划、专员、细纲、审查统一使用已有公共请求发送器，启用流式。预先呈现输出区，卡片可以展开／收起，分类后的子项也能展开。原文入口打开独立弹窗，支持返回分类内容与 Escape 返回，不会关闭下面的方案。
- **中断保留**：流式回调及时更新各区块原文。停止、长度截断或传输中断时保留已收到文字；可识别的结果进入待确认草稿，尚不能解析的原文仍可查看，不当作完整结果覆盖书籍。完整细纲保留，半截新增细纲标为未完成，重试只补缺章；重试前原文另留一份。已开始输出后不自动重发并覆盖半截内容。
- **多级输入**：过滤空记录，批次范围限制为有限整数，防止异常范围造成无限循环；任务运行时拦截重复启动和单块重试。
- **Gemini 联动**：作者原话单独带 `_moyunUserInput` 标记；模板与生成的资料不带该标记。团队请求和原有一键开书共用输入改写、抗截断及协议解析。
- **细纲分支**：没有正文时也能创建并进入规划分支，复制至选中章的细纲与实际已有正文。正文入口找不到目标章节时有 toast，不再无反馈。嵌套规划分支同样可用。
- **分支编号**：新增章节标题按当前分支的位置编号；角色状态与故事记忆事件使用章节所属分支的章号；自动总结只统计当前分支，不再把全书存储条数当章号。
- **未完模式**：两种关闭入口共用二次确认，明确说明关闭后不可返回。取消不改数据；确认后把关闭状态随书保存；切书后旧确认不会改到新书。

没有新建书籍数据的 localStorage 键，没有新增请求直连流程。源模板仍是 `source/moyun.single.html`，`index.html`、`assets/css/moyun.css`、`assets/js/moyun.js` 已在主目录由构建同步。

## 2026-11-15 续写后的大纲工作台补充修复
